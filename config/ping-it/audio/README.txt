Ping It! custom sounds

QUICK EXAMPLE
1. Put a file named andrey.ogg directly in this folder.
2. Open Ping It! settings -> General -> Sound.
3. Under Custom Sounds, press Reload.
4. Paste metki:custom/andrey into a Look, Alert, or Danger Sound ID field.
5. Press the > button next to the field to test the sound.

IMPORTANT
- Do not include .ogg in the Sound ID.
- Use real OGG/Vorbis audio. Renaming an MP3 file to .ogg will not work.
- Put files directly in this folder, not in a subfolder.
- For predictable IDs, use lowercase latin letters, numbers, _ or - in file names.

FILE NAME                  SOUND ID
andrey.ogg                 metki:custom/andrey
danger_warning.ogg         metki:custom/danger_warning

These sounds are local. They are never uploaded to a server or another player.
