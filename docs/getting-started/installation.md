# Установка модпака

Подробное руководство по установке **Aeronautics Sky Islands**.

---

## 📋 Системные требования

### Минимальные требования

| Компонент | Требование |
|-----------|------------|
| **Minecraft** | 1.20.1 |
| **Mod Loader** | Fabric |
| **ОЗУ** | 4 GB |
| **Процессор** | Intel i3 / AMD Ryzen 3 |
| **Видеокарта** | Integrated Graphics |

### Рекомендуемые требования

| Компонент | Требование |
|-----------|------------|
| **ОЗУ** | 8 GB |
| **Процессор** | Intel i5 / AMD Ryzen 5 |
| **Видеокарта** | GTX 1050 / RX 560 |

!!! warning "Важно"
    Выделите минимум **6 GB** оперативной памяти для игры в настройках лаунчера!

---

## 🚀 Способы установки

### Способ 1: Через лаунчер (Рекомендуется)

=== "Prism Launcher"

    **Шаг 1:** Скачайте [Prism Launcher](https://prismlauncher.org/)
    
    **Шаг 2:** Откройте лаунчер и нажмите **Add Instance**
    
    **Шаг 3:** Выберите **Modrinth** в левом меню
    
    **Шаг 4:** Найдите "Aeronautics Sky Islands"
    
    **Шаг 5:** Нажмите **OK** и дождитесь установки
    
    **Шаг 6:** Запустите игру!

=== "CurseForge App"

    **Шаг 1:** Скачайте [CurseForge App](https://www.curseforge.com/download/app)
    
    **Шаг 2:** Перейдите в раздел **Minecraft**
    
    **Шаг 3:** Нажмите **Browse Modpacks**
    
    **Шаг 4:** Найдите "Aeronautics Sky Islands"
    
    **Шаг 5:** Нажмите **Install**
    
    **Шаг 6:** Запустите через лаунчер!

=== "ATLauncher"

    **Шаг 1:** Скачайте [ATLauncher](https://atlauncher.com/)
    
    **Шаг 2:** Откройте вкладку **Packs**
    
    **Шаг 3:** Найдите "Aeronautics Sky Islands" через поиск
    
    **Шаг 4:** Нажмите **New Instance**
    
    **Шаг 5:** Дождитесь установки
    
    **Шаг 6:** Играйте!

---

### Способ 2: Ручная установка

!!! tip "Для опытных пользователей"
    Этот способ подходит, если вы хотите полный контроль над установкой.

**Шаг 1:** Установите [Fabric Loader](https://fabricmc.net/use/installer/)

**Шаг 2:** Скачайте [Fabric API](https://modrinth.com/mod/fabric-api)

**Шаг 3:** Скачайте архив модпака с [Modrinth](https://modrinth.com/modpack/aeronautics-sky-islands)

**Шаг 4:** Распакуйте в папку `.minecraft/`

**Шаг 5:** Запустите Minecraft Launcher и выберите профиль Fabric

---

## ⚙️ Настройка после установки

### Выделение памяти

1. Откройте настройки лаунчера
2. Найдите раздел **Memory** или **Java Arguments**
3. Установите минимум **6144 MB** (6 GB)
4. Пример: `-Xmx6G -Xms4G`

### Настройка графики

При первом запуске рекомендуем:

- **Video Settings → Render Distance**: 8-12 чанков
- **Video Settings → Graphics**: Fast (для слабых ПК)
- **Шейдеры**: Выключены (если тормозит)

## 🐛 Решение проблем

### Игра не запускается

!!! danger "Крэш при запуске"
    **Причина**: Недостаточно памяти
    
    **Решение**: Выделите больше ОЗУ в настройках лаунчера

### Низкий FPS

!!! warning "Тормоза"
    **Решения:**
    
    - Снизьте render distance до 8
    - Выключите шейдеры
    - Установите Graphics: Fast
    - Закройте лишние программы

### Моды не загружаются

!!! bug "Ошибка загрузки"
    **Причина**: Неправильная версия Fabric
    
    **Решение**: Переустановите модпак через лаунчер

## ✅ Проверка установки

После запуска игры проверьте:

- [ ] В главном меню отображается "Aeronautics Sky Islands"
- [ ] В списке модов есть Aeronautics и Create
- [ ] При создании мира генерируются летающие острова
- [ ] Нет ошибок в консоли
