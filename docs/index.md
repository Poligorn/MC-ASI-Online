# Aeronautics Modpack — Документация

Добро пожаловать в техническую документацию модпака **Aeronautics** с механиками EVE Online!

## 🚀 О проекте

Это большая сборка для Minecraft, основанная на моде **Aeronautics** с интеграцией механик из EVE Online: экономикой, собственными модами и новыми рецептами.

## 🛠️ Основные разделы

### [Моды](mods/index.md)
Список и описание всех модов в сборке, включая Aeronautics и кастомные моды.

### [Механики](mechanics/index.md)
Игровые механики: интеграция с EVE Online, экономика, космические корабли, добыча ресурсов.

### [Рецепты](recipes/index.md)
Базовые и продвинутые рецепты крафта, включая корабли и компоненты.

### [Разработка](development/index.md)
Руководства для разработчиков команды: добавление модов, создание рецептов, тестирование.

## 🔧 Инструменты

Модпак использует:
- **[Packwiz](https://packwiz.infra.link/)** — управление модами через Git
- **GitHub Actions** — автоматическая сборка
- **MkDocs** — документация
